# v1.1.0

## 新功能

- 搜索页重构为实时模糊搜索，输入即搜（200ms 防抖）
- 预建中英双语搜索索引，跨分类统一排名（5567 条数据，13ms 构建）
- 搜索结果卡片化展示，含分类标签、相关度进度条、关键词高亮
- 搜索结果点击打开右侧详情抽屉
- 详情页按分类专属渲染：
  - 角色：天赋 / 战斗天赋 / 被动天赋 / 命之座 / 声优
  - 武器：属性 + R1~R5 精炼效果
  - 圣遗物：套装效果 + 5 个部位（花/羽/沙/杯/头）
  - 材料：类型 + 来源
- 图片优先使用 Enka CDN（enka.network/ui/），提升加载速度

## 优化

- `getItemImage` 优先使用 `filename_*` 字段拼接 Enka CDN URL
- `extractSummary` 增加 `imageUrl` 字段，百科卡片图片加载更快

## 修复

- 修复搜索结果展示为原始 JSON 的问题，改为结构化卡片

## 技术细节

- 新增 `GenshinService.buildIndex()` / `fuzzySearch()` / `resolveImage()` 方法
- 新增 `/api/search-index` 接口
- 配置中增加 `enkaCdn` 和 `folderLabels`
- 新增 24 个测试用例（索引构建、模糊搜索、图片解析、新接口）
